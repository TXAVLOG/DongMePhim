# 🎬 DongMePhim (TPHIMX) - Nền tảng Xem phim Trực tuyến Cao cấp

Nền tảng xem phim trực tuyến hiện đại, chất lượng cao và hoàn toàn miễn phí, được tối ưu hóa hiệu năng, giao diện và bảo mật ở mức cao nhất.

---

## 🚀 Tính năng nổi bật

- 💎 **Giao diện kính mờ (Glassmorphic Design):** Thiết kế sang trọng, hiện đại, hỗ trợ Responsive 100% trên các thiết bị di động, máy tính bảng và máy tính.
- ⚡ **Tốc độ truyền tải siêu tốc:** Sử dụng trình phát thích ứng thông minh (ArtPlayer) kết hợp hạ tầng Cloudflare CDN giúp tải video mượt mà không giật lag.
- 🔒 **Quản lý quyền riêng tư & Bảo mật:** Tích hợp xác thực phân quyền, lưu trữ lịch sử xem cục bộ qua LocalStorage và mã hóa dữ liệu đầu cuối.
- 🛠️ **Cấu hình hệ thống động:** Admin có thể bật tắt chế độ bảo trì, chỉnh sửa các liên kết mạng xã hội chính thức (Facebook Fanpage, Group, Telegram, Zalo), cấu hình SMTP và API Security.
- 📝 **Nội dung phong phú:** Hỗ trợ phim bộ, phim lẻ, phân loại theo thể loại, quốc gia, diễn viên, chủ đề và lịch chiếu được cập nhật liên tục.

---

## 🛠️ Công nghệ sử dụng

- **Core Framework:** [Astro v6](https://astro.build/) - Tối ưu hóa tốc độ tải trang tĩnh và SSR hoàn hảo.
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) - Thiết kế giao diện hiện đại và nhanh chóng.
- **Interactive UI:** [React v19](https://react.dev/) - Sử dụng cho các thành phần điều khiển trình phát video và danh sách tương tác.
- **Trình phát Video:** [ArtPlayer](https://artplayer.org/) - Trình phát HTML5 linh hoạt hỗ trợ nhiều luồng phát dự phòng.
- **Hạ tầng & Hosting:** [Cloudflare Pages & Workers](https://pages.cloudflare.com/) - Đảm bảo khả năng chịu tải cực cao và phân phối nội dung toàn cầu.

## 🧞 Lệnh chạy dự án

Tất cả các lệnh được chạy từ thư mục gốc của dự án thông qua terminal:

| Lệnh | Mô tả |
| :--- | :--- |
| `npm install` | Cài đặt toàn bộ thư viện và phụ thuộc cần thiết |
| `npm run dev` | Khởi động máy chủ phát triển cục bộ tại `http://localhost:4321` |
| `npm run build` | Biên dịch toàn bộ dự án cho môi trường production |
| `npm run preview` | Chạy xem trước bản build cục bộ để kiểm tra trước khi deploy |
| `npm run deploy` | Biên dịch và triển khai trực tiếp lên Cloudflare Pages |
